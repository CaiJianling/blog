## 三项改动方案

### 任务 1 — AI 小助手「启用」开关改用液态玻璃
当前 `ai.tsx:546` 的助手启用开关是普通 Radix `Switch`。`/users` 用户管理页已有一个「特效开→液态玻璃、特效关→普通开关」的 `StatusSwitch` 本地组件（`User/Index.tsx:130`），把它抽成共享组件复用。

- **新建** `resources/js/components/status-switch.tsx`：导出 `StatusSwitch({ checked, onCheckedChange, disabled })`，内部 `useEffects()` 判断 `effectsEnabled` → 开则渲染 `<LiquidSwitch checked onChange size="sm">`，关则渲染 Radix `<Switch>`（行为与 `User/Index.tsx:130-153` 完全一致）。
- `resources/js/pages/settings/ai.tsx`：助手启用开关（546-551）换成 `StatusSwitch`。
- `resources/js/pages/User/Index.tsx`：删掉本地 `StatusSwitch`（130-153），改 import 共享组件，消除重复。

### 任务 2 — 侧边栏：新增「评论管理」分组
现在「评论」是顶级叶子项（`app-sidebar.tsx:105`），「表情管理」是「内容管理」分组的子项（admin，135-138）。改为：

- 删除顶级「评论」叶子项；从「内容管理」children 移除「表情管理」。
- 在原「评论」位置新增 **评论管理** 分组（图标 `MessageSquare`），children = 「评论」（所有角色可见）；在 `isAdmin` 分支里往该分组 children 追加「表情管理」（仅 admin）。
- i18n：`zh.json` / `en.json` 新增 `commentManagement.title`（评论管理 / Comment Management）。

### 任务 3 — 站点 + 文章/页面 SEO（完整）
**站点级**（保留站点标题/副标题，站点标题同时作为站点 SEO 标题与 `og:site_name`）：
- `resources/js/pages/site-settings.tsx`：在通用区后新增独立「SEO」区块，含 `seo_description`（站点描述，Textarea）+ `seo_keywords`（站点关键词，Input）。
- `app/Http/Controllers/OptionController.php`：`SITE_OPTION_KEYS` 与 `update()` 校验新增 `seo_description`(nullable,max:500)、`seo_keywords`(nullable,max:200)。
- `app/Http/Middleware/HandleInertiaRequests.php`：`share()` 新增 `seo` 共享 props（`title=site_title`、`description=seo_description`、`keywords=seo_keywords`），供前台各页输出 meta。

**文章/页面逐项 SEO**：
- 新迁移 `add_meta_seo_to_articles_and_pages`：`articles` 与 `pages` 各加 `meta_title`(string,nullable)、`meta_description`(text,nullable)。
- 模型 `$fillable` 增加两字段。
- `ArticleController`（store/update 校验+保存、edit props）与 `PageController`（同）补全两字段。
- 编辑器 `Article/Edit.tsx`、`Article/Create.tsx`、`Page/Edit.tsx`、`Page/Create.tsx`：侧栏新增「SEO」`SidebarSection`，含 SEO 标题(Input) + SEO 描述(Textarea)。

**前台 meta 输出**（新建 `resources/js/lib/seo.ts` 的 `buildSeoMeta()` 统一生成 meta 数组，避免重复）：
- `Blog/Show.tsx:228`：`<Head title={meta_title||title} meta={…}>` 输出 description(=meta_description||excerpt)、og:title/description/type=article/url/site_name、twitter:card/title/description。
- 站点页 `Home.tsx`（当前无 Head）、`Blog/Index.tsx`、`Tools/Index.tsx`、`Nav/Index.tsx`：用共享 `seo` props 输出站点 description/keywords + og:site_name/title/description。
- 说明：`Page` 模型目前仅后台 CRUD、无前台渲染组件，故页面 SEO 字段与编辑器先就位（SEO-ready），前台 meta 输出待页面有公开路由时接入。

**i18n**：`settings.site.seo / seoDescription / seoDescriptionDescription / seoKeywords`；`articles.form.seoTitle / seoTitleDescription / seoDescription / seoDescriptionDescription`；`pages.form.seoTitle / seoDescription`（zh + en）。
