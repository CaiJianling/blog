## 四项优化：代码框 / 提示气泡 / 滚动条 / 小助手窗口

### 需求 1：代码框
**涉及**：`app.css`、`blocknote-to-html.ts`、`Blog/Show.tsx`、`package.json`

1. **代码靠左对齐**（根因：`<pre>` 从祖先继承 `text-align: center`）
   - `app.css`：给 `:is(.code-block, .code-block__stage) .code-block__pre` 显式 `text-align: left`。

2. **隐藏行号：加过渡动画 + 修「空行消失」bug**
   - bug 根因：空代码行的 `.cb-line` 在行号隐藏后无内容 → 高度坍缩为 0（实测 9 行只剩 7 行）。修复：`.cb-line { min-height: 1.7em }`（等于行高，空行保留高度，非空行不受影响）。
   - 过渡：把 `.cb-ln` 从 `display:none` 改为「宽度收缩 + 淡出」。`.cb-ln` 用固定 `width: 2.4em`，`transition: width/opacity/margin-right/padding-right/border-color .2s`；`.no-ln .cb-ln` 设 `width:0; opacity:0; margin-right:0; padding-right:0; border-right-color:transparent; overflow:hidden`。行号消失时代码平滑左移。

3. **全屏补上 3 个功能按钮 + 开合过渡**
   - `Show.tsx` 的 `openFullscreen()`：头部改成「圆点 + 隐藏行号/折行/复制 + 关闭」，功能按钮作用在**舞台元素**（对 `.code-block__stage` 切换 `no-ln`/`wrap`，复制取舞台内文本）。
   - `app.css`：把开关选择器由 `.code-block.no-ln` / `.code-block.wrap` 扩成 `:is(.code-block, .code-block__stage).no-ln` / `:is(.code-block, .code-block__stage).wrap`，让全屏舞台同样生效。
   - 开合过渡：给 `.code-block-overlay`/`.code-block__stage` 加进入 keyframe（淡入 + 轻微缩放）；关闭时加 `.closing` 类播退出动画，结束后移除。

4. **代码高亮**（新增依赖 `highlight.js`）
   - `package.json`：`npm i highlight.js`；`blocknote-to-html.ts` 用 `hljs/lib/core` 注册编辑器 `CODE_LANGUAGES` 对应的高亮语言（js/ts/jsx/tsx/html/css/json/python/bash/powershell/sql/go/rust/java/c/cpp/csharp/php/ruby/yaml/markdown/diff）。
   - 整块 `hljs.highlight(code, { language, ignoreIllegals })` 后，用一个小工具函数按换行切分并**跨行保留 span**（highlight.js 仅输出 `<span>`，切分时在换行处闭合再重开），得到带 class 的逐行 HTML，再套 `.cb-line`/`.cb-ln`。未知语言回退纯文本。
   - `app.css`：新增 `hljs-*` 令牌配色（奶油浅色 + 深色两套），配一套协调色板。

### 需求 2：美化提示气泡（tip）
- **代码框 4 按钮**（静态 HTML，非 React）：`blocknote-to-html.ts` 把 `title` 换成 `data-tip`；`app.css` 用 `::after`（`content: attr(data-tip)`）+ `::before` 箭头做深色圆角气泡，hover/focus 淡入下滑。为不被 `.code-block { overflow:hidden }` 裁切，把容器 `overflow:hidden` 去掉、改由 `background-clip`（默认）+ 头部/底部子元素圆角实现圆角，气泡向下弹出。
- **右下角悬浮按钮**（`floating-actions.tsx`，React）：`title` → 现成的 Radix `<Tooltip>`（app.tsx 已全局 `TooltipProvider`），内容传 `className` 覆盖默认蓝底为深色玻璃风（`bg-zinc-900/95 text-white border-white/10 backdrop-blur-sm shadow-lg`）。
- **小助手悬浮按钮**（`ai-assistant-widget.tsx`）：同样 `title` → Radix `<Tooltip>` 深色风。

### 需求 3：美化滚动条
`app.css` 全局统一：
- `:root { scrollbar-width: thin; scrollbar-color: <thumb> transparent; }`
- `*::-webkit-scrollbar { width/height: 10px }`、`::-webkit-scrollbar-track { background: transparent }`、`::-webkit-scrollbar-thumb { 半透明圆角, background-clip: content-box }`、hover 加深、`.dark` 变体。
- 一处覆盖**页面主滚动条、大纲下拉栏、后台侧边栏**及所有内滚区（代码块、聊天等），细、圆角、半透明。

### 需求 4：小助手窗口（磨砂 + 开合动效）
`ai-assistant-widget.tsx`：
- 面板背景由实心 `bg-popover` 改为磨砂玻璃：`bg-white/70 dark:bg-zinc-900/60 backdrop-blur-2xl backdrop-saturate-150`，加细边框 + 顶部高光/渐变营造层次（不止半透明）。
- 开合动效用现成的 `framer-motion`：`AnimatePresence` + `motion.div`，面板 `initial/animate/exit`（opacity + y + scale，transformOrigin 右下，spring），悬浮按钮打开时同样过渡退出。
