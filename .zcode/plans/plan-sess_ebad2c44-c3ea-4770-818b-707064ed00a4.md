## 后台「主题设置」：单主色，全站（前后台）生效

**方案**：管理员只选一个主色（`theme_color`，hex）。强调色(accent)、选中环(ring)、侧边栏高亮、图表首色等由该主色自动派生，全站（前台+后台共用同一套 CSS 变量，都经 `app.blade.php` 渲染）生效。存储用现有 `Option` 模型（key/value），**空值 = 用内置默认蓝**（不覆盖，保持现状）。无需建表/迁移，也无缓存需失效（`Option` 每次直读 DB，存一次下次请求即生效）。

**生效原理**：全站颜色是 `:root`/`.dark` 里的 CSS 变量（`--primary` 等），组件用语义类（`bg-primary`→`var(--color-primary)`→`var(--primary)`）。所以在 `<head>` 里条件注入一段 `<style>` 覆盖由主色派生的那 9 个变量（用 `color-mix` 派生半透明色），即可让整站跟随，无需改任何组件。放在 `<head>`（`@vite` 之后）→ 无 FOUC、SSR 正确。

### 改动文件（9 处）

**1. 新建 `app/Http/Controllers/ThemeSettingController.php`**（仿 `FooterSettingController`）
- `public const PRESETS = [...]`（约 8 个预设色：默认蓝 `#0071e3` + 靛/紫/玫红/橙/绿/青/红）。
- `edit()`：`Inertia::render('settings/theme', ['themeColor' => (string) Option::get('theme_color',''), 'presets' => self::PRESETS])`。
- `update(Request $request)`：归一化（补 `#`、小写）→ 校验 `theme_color`（`nullable` + `regex:/^#[0-9a-fA-F]{6}$/`）→ `Option::set('theme_color', $value)` → `to_route('theme.edit')->with('toast', [...])`。空值即清除→恢复默认。

**2. `routes/web.php`**（`AdminMiddleware` 组内，仿其它 settings 路由）
- `Route::get('settings/theme', [..., 'edit'])->name('theme.edit');`
- `Route::put('settings/theme', [..., 'update'])->name('theme.update');`

**3. `app/Http/Middleware/HandleAppearance.php`**：在 `handle()` 里追加 `View::share('theme_color', (string) Option::get('theme_color',''));`（该中间件已在 `web` 组，覆盖所有页面，`app.blade.php` 可用）。

**4. `resources/views/app.blade.php`**：在 `@vite(...)`（第 41 行）之后加
```blade
@if($theme_color ?? '')
<style>
  :root { --primary: {{ $theme_color }}; --accent-foreground: {{ $theme_color }}; --accent: color-mix(in srgb, {{ $theme_color }} 10%, transparent); --ring: color-mix(in srgb, {{ $theme_color }} 45%, transparent); --chart-1: {{ $theme_color }}; --sidebar-primary: {{ $theme_color }}; --sidebar-accent-foreground: {{ $theme_color }}; --sidebar-accent: color-mix(in srgb, {{ $theme_color }} 10%, transparent); --sidebar-ring: color-mix(in srgb, {{ $theme_color }} 35%, transparent); }
  .dark  { --primary: {{ $theme_color }}; --accent-foreground: {{ $theme_color }}; --accent: color-mix(in srgb, {{ $theme_color }} 16%, transparent); --ring: color-mix(in srgb, {{ $theme_color }} 55%, transparent); --chart-1: {{ $theme_color }}; --sidebar-primary: {{ $theme_color }}; --sidebar-accent-foreground: {{ $theme_color }}; --sidebar-accent: color-mix(in srgb, {{ $theme_color }} 18%, transparent); --sidebar-ring: color-mix(in srgb, {{ $theme_color }} 45%, transparent); }
</style>
@endif
```
（覆盖 `app.css` 中由主色派生的 9 个变量；`:root`/`.dark` 各按现有深浅色透明度；放 `@vite` 之后以保证层叠胜出。）

**5. 新建 `resources/js/pages/settings/theme.tsx`**：`AdminSettingsShell`（非宽，紧凑表单）+ 一个 Card：
- 颜色选择：原生 `<input type="color">` + hex 文本框（本地 state 同步），预设色板（`presets`）点击选中，`恢复默认`（清空→内置蓝），保存按钮。
- 保存用 `router.put('/settings/theme', { theme_color })`（仿 `settings/ai.tsx`，`onFinish` 弹 toast、清空可编辑态）；值经隐藏 `<input name="theme_color">` 提交。
- 可选：一个用当前色渲染的小预览（示例按钮/链接）。

**6. `resources/js/components/app-sidebar.tsx`**：`import { edit as editTheme } from '@/routes/theme';`，在 settings 组 `children` 里加 `{ title: 'settings.theme.title', href: editTheme() }`。

**7. `resources/js/locales/zh.json` + `en.json`**：加 `settings.theme` 段：`title`（导航"主题"）、`heading`、`description`、`primaryColor`、`primaryColorHint`（"强调色/选中环/侧边栏高亮等自动跟随主色"）、`presets`、`custom`、`reset`（复用 `common.save`/`common.saving`）。**注意用单花括号以外的普通文案**（勿误写插值）。

**8. 重新生成 Wayfinder**：`php artisan wayfinder:generate` → 生成 `resources/js/routes/theme/index.ts`（供 `editTheme()` 用）。

**9. 测试 `tests/Feature/ThemeSettingTest.php`**（仿现有 `FooterSettingTest`/`SidebarSettingTest`）：`edit` 渲染（含 presets/当前值）、`update` 有效 hex→写入 Option、非法值→校验错、空值→清除、非管理员→403/重定向。
