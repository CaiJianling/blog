## 统一设置页样式 + 带鱼屏居中限宽

以「前台显示」（home.tsx，卡片分节 + 全宽）为基准，把 **站点设置 / AI 设置 / 固定链接** 三页对齐为同一套「卡片分节（图标头 + 内容 + 右下角保存）+ 统一居中限宽」外观，并解决带鱼屏（超宽屏）内容过宽、需左右长距离定位的问题。

（未收到选项回复，采用推荐值：**限宽 1500px 居中**、**完整改卡片**；该数值集中在外壳里，后续可调。）

### 改动文件（4 个）

**1. `resources/js/components/admin-settings-shell.tsx`（核心·宽度）**
- `wide` 分支由 `''`（撑满）改为 `mx-auto w-full max-w-[1500px]`（居中 + 限宽 1500px，≈16:9 观感）。
- 效果：所有 `wide` 页在 1366/1080P 上接近满宽，2K 与带鱼屏自动居中并留两侧边距。
- non-wide（672px）分支保持不变（navigation-intro 不受影响）。
- 副产物：navigation / tools / smilies（内容管理组，同用该外壳）也会获得 1500px 居中限宽，整体更一致，低风险。

**2. `resources/js/pages/settings/ai.tsx`（仅宽度）**
- `AdminSettingsShell` 增加 `wide`（从 672px → 与参考一致的 1500px 居中）。其卡片样式本已与参考一致，无需改结构。

**3. `resources/js/pages/site-settings.tsx`（改卡片 + 宽度）**
- `AdminSettingsShell` 增加 `wide`。
- 仿 home.tsx 增加内联辅助函数 `cardHeader(icon, title)`（图标盒 + 标题 + 底边框）与 `saveButton(saving)`（顶边框 + 右下角 保存/保存中，`type="submit"`）。
- 4 个分节（行 294/515/564/668 的 `<div className="space-y-6">` + `<h3>`）各自改为：`<Card className="gap-0 overflow-hidden py-0">` → `cardHeader(<图标>, 标题)` → `<CardContent className="space-y-4 px-6 py-5">`（内部字段、隐藏 input 保持不变）。
  - 图标：常规=`Settings`、SEO=`Search`、语言/时区=`Languages`、日期/时间格式=`CalendarClock`。
  - 标题沿用现有 `t('settings.site.general/seo/…')` 文案。
- 删除结尾独立保存按钮（行 917–921），改为在**最后一个**卡片 CardContent 底部渲染 `saveButton(processing)`（仍在同一 `<Form>` 内，一次提交）。

**4. `resources/js/pages/settings/permalink.tsx`（改卡片 + 宽度）**
- `AdminSettingsShell` 增加 `wide`。
- 同样增加 `cardHeader`/`saveButton` 辅助函数。
- 2 个分节（常用设置、可选）各自改为 Card + cardHeader + CardContent。图标：常用=`Link`、可选=`SlidersHorizontal`。
- 「保存更改」按钮移入最后一个卡片底部 `saveButton(processing)`（文案统一为 保存/保存中，与参考一致）。

### 不改动
- home.tsx（参考）：已是 `wide` + 卡片，宽度改造后自动获得 1500px 居中，无需改代码。
- 各页字段、校验、提交接口、隐藏 input、i18n 键均不动（仅外层容器与结构包装变化）。
